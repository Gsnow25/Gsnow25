### 🚀 Sobre Mí

Soy desarrollador de software enfocado en construir **soluciones tecnológicas escalables y listas para producción**. Me especializo en el diseño e implementación de ecosistemas multiplataforma (Móvil, Web y Escritorio), optimizando procesos operativos mediante arquitecturas limpias, bases de datos sólidas e integraciones en tiempo real.

- 💼 **Enfoque Técnico:** Desarrollo Full-Stack (Flutter / PHP / JS), Diseño de Esquemas SQL y Despliegue con Docker.
- ⚡ **Experiencia en Producción:** Desarrollo de sistemas de gestión institucional, control de asistencia por QR de alta velocidad, paneles administrativos con autenticación OTP y reportería automatizada.
- 🔧 **Hardware & IoT:** Integración de microcontroladores (ESP32 / C++) con sensores y transmisión de telemetría vía HTTP a la nube.
